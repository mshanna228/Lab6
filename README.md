# Лабораторная работа №6 (Вариант 486081)

Клиент-серверное приложение на базе протокола UDP с использованием DatagramChannel (неблокирующий режим) и Stream API для управления коллекцией объектов.

## Требования для запуска
- **Java JDK 17** или выше.
- Для проверки версии Java выполните в консоли:
  ```bash
  java -version
  ```

---

## Способ 1: Запуск через Gradle (быстрый старт для разработки)

Для запуска потребуются **два независимых окна терминала** (командной строки). Откройте их в корневой директории проекта.

### 1. Запуск сервера (в первом терминале)
Серверу необходимо передать путь к JSON-файлу коллекции в качестве аргумента:
* **Windows (PowerShell / CMD):**
  ```powershell
  .\gradlew.bat :server:run --args="collection.json"
  ```
* **macOS / Linux (Bash / Zsh):**
  ```bash
  ./gradlew :server:run --args="collection.json"
  ```

### 2. Запуск клиента (во втором терминале)
Клиент по умолчанию подключается к `localhost:1821`:
* **Windows (PowerShell / CMD):**
  ```powershell
  .\gradlew.bat :client:run
  ```
* **macOS / Linux (Bash / Zsh):**
  ```bash
  ./gradlew :client:run
  ```

---

## Способ 2: Сборка и запуск через JAR-файлы (рекомендуемый)

Сборка JAR-архивов позволяет запускать клиент и сервер независимо от Gradle.

### 1. Сборка проекта
Выполните сборку в корневой директории:
* **Windows:**
  ```powershell
  .\gradlew.bat build
  ```
* **macOS / Linux:**
  ```bash
  ./gradlew build
  ```
После успешной сборки сгенерированные исполняемые JAR-файлы появятся в директориях:
- `server/build/libs/server.jar`
- `client/build/libs/client.jar`

### 2. Запуск сервера (в первом терминале)
Перейдите в терминале в корень проекта и запустите:
```bash
java -jar server/build/libs/server.jar collection.json
```

### 3. Запуск клиента (во втором терминале)
Запустите клиентское приложение:
```bash
java -jar client/build/libs/client.jar
```
*По умолчанию клиент подключается к `localhost:1821`. При необходимости адрес и порт можно переопределить через аргументы запуска:*
```bash
java -jar client/build/libs/client.jar <хост> <порт>
# Пример:
java -jar client/build/libs/client.jar localhost 1821
```

## Доступные команды

### В консоли сервера:
* `save` — принудительно сохранить текущее состояние коллекции в JSON-файл.
* `exit` — сохранить коллекцию и безопасно завершить работу сервера.

### В консоли клиента:
Введите `help` после подключения к серверу, чтобы вывести список всех команд управления коллекцией (например, `info`, `show`, `add`, `update`, `remove_by_id`, `clear`, `execute_script`, `exit` и др.).
